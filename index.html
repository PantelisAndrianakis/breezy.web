Code that reads clean.

Breezy is a statically-typed, object-oriented language that compiles directly to native machine code - with memory and concurrency handled automatically by the language. The ergonomics you want, with a tiny footprint and predictable, pause-free latency.

Greeter.bzy 
class Greeter
{
    string name;

    void init(string who)
    {
        name = who;
    }

    void greet()
    {
        print("Hello, " + name + "!");
    }
}

void main()
{
    Greeter g = new Greeter();
    g.init("Breezy");
    g.greet();              // Prints: Hello, Breezy!
}
Why Breezy

The convenience of automatic.
The footprint of native.

Most high-level languages buy their convenience with a heavier runtime. Breezy refuses that trade - every design choice keeps the binary small and the latency flat.

🚀

Native execution

Compiles directly to x86-64 machine code, with hot numeric loops handed to GCC's optimizer. No interpreter, no bytecode, no JIT warm-up - your program is the binary.

🪶

Low memory usage

Automatic Reference Counting releases objects the moment they are no longer referenced, keeping memory close to live data.

⚡

Predictable latency

No stop-the-world heap scans. Reclamation is incremental, with a bounded cycle collector only for reference cycles.

🧵

Scalable concurrency

Lightweight coroutines - “breezes” - multiplex huge numbers of concurrent tasks over a small pool of OS threads.

🔌

Direct native interop

Objects never move in memory, so pointers pass straight to native libraries - no pinning, no copying, no marshalling tax.

✍️

Automatic resources

Memory and concurrency are the language’s job - no manual deallocation, ownership tracking, or lifetime bookkeeping in your code.

Get started

Clone, build, run

Grab a prebuilt compiler for Windows or Linux from the latest release — or pull the repo and build it yourself. No package registry to configure, no toolchain zoo.

bash
# Get the source
$ git clone https://github.com/PantelisAndrianakis/Breezy
$ cd Breezy

# Build the compiler
$ make breezy

# Compile and run a program
$ ./breezy Greeter.bzy
